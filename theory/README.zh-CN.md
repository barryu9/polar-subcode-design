# 证明中的有限算例核查

[English](README.md) · **简体中文**

在仓库根目录运行下列命令。第一条按正文顺序核查全部八项结论。第二条沿用同一对分量码，依次核对联合观测、系数恢复，以及仿射域上的距离判据。每核对完一项，脚本就会打印一行结果。[理论核查代码](check_results.py)

```bash
python -m theory.check_results
python -m theory.check_results theorem2 proposition3 corollary1
```

**从一个外层矩阵读起。** 先看脚本中的 `theta_data()`。左右分量码的码长都是 4。左侧有两个信息来源，每个来源在外层矩阵 $T$ 中对应一列，每列有两个系数，所以共有 16 个矩阵。对于每个赋值 $t=\operatorname{vec}(T)$，`observations[t]` 存放各条关键消息的校验子观测 $Q_a Tm$。另一条计算路径直接编码父码的所有消息，将各重量的码字数 $(A_0,A_1,A_2)$ 存入 `spectra[t]`。可以沿着这两份数据对照理论预测与实际码字。

定理 2 的核查结果给出截止重量 $D=2$ 时的秩为 2，因此共有四个可达的联合观测。命题 3 为每个观测保留一个代表元，将它分别与联合核中的四个元素相加，即可恢复具有同一观测的全部四个矩阵。推论 1 继续使用这 16 个矩阵，检验哪些仿射域的**每一个**赋值都达到距离目标。

| 论文结论 | 核查内容 |
|---|---|
| 命题 1，式 (8) | 将长度 8 的系数配置按保留的系数分组，逐组核对低重量码字集合。 |
| 定理 1，式 (13)–(14) | 围绕一个非零基准改变四个系数。按来源模式得到残差计数，再与直接编码得到的各禁止重量层码字比较，核对共享系数下的联合排除和逐重量计数。 |
| 定理 2，式 (23)–(25) | 对同一小规模极化分解的全部 16 个外层矩阵，核对完整重量枚举式和所有保谱平移，并穷举线性映射可能的核，检验最小秩结论。 |
| 命题 2，式 (30) | 对 502 组码及截止重量，将算法 1 的输出与直接枚举的输入列表排序后逐项比较。排序保留重复项，因此能够检出重复输出。 |
| 命题 3，式 (33)–(34) | 从代表元和核向量恢复完整可行集，核对每一来源可提供的联合观测、列之间具有关联约束的仿射原像，以及各列受限后的像。 |
| 推论 1，式 (35) | 遍历四参数系统的全部 307 个仿射域，逐点计算精确码字数，核对域内每个配置均达到距离目标是否等价于各消息的可达观测集均避开相应禁止集。 |
| 定理 3，式 (36)、(39)–(40) | 分别对固定分量码条件和公共超码条件，在每个前缀比较条件均值与实际违反条件的次数。严格均值界成立时，沿均值较小的子分支继续。下一项也逐个核查每个已接受的前列赋值的可延伸数。 |
| 推论 2，式 (42)–(46) | 核对例 7 的分量码包含关系与秩条件，然后对每个已接受的部分赋值，按投影条件清点下一列的可行选择。 |

**怎样读例 7 的计数。** 运行 `python -m theory.check_results corollary2`，输出中的 `Lambda=[8, 16], lower bound 13440, exact 13472` 给出两步逐源赋值的结果。每列各有 128 种候选值，第一列至多排除 8 种。任取一个已接受的第一列，第二列都至多排除 16 种。因此至少有 $(128-8)(128-16)=13{,}440$ 个外层矩阵可行。按实际禁止集逐一计数，达到 $d_\star=6$ 的矩阵共有 13,472 个。利用这两个来源组构造外层矩阵的过程见[例 7](../paper_examples/example07.py)。
